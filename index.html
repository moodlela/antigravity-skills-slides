七、最建議的安裝組合

不建議一次安裝所有技能，容易造成混淆或過度消耗 Token。建議分階段載入：

第一階段：商業基礎組

  • create-business (商業模式)
  • customer-research (需求調查)
  • marketing-plan (行銷推廣)
  • copywriting (文案寫作)
  • internal-comms (日常週報)

第二階段：營運成長組

  • revenue-operations (銷售管線)
  • customer-success (續約健康)
  • sales-enablement (銷售素材)
  • pricing (定價包裝)
  • proposal-writer (合約提案)

第三階段：產品管理組

  • product-manager-toolkit
  • competitor-profiling (競品)
  • analytics (數據分析)
  • launch (上線管理)

八、AntiGravity 安裝方式

建議將專案用 Skill 放在工作區根目錄，隨專案代碼一起進行 Git 版本管理：

<workspace-root>/.agents/skills/<skill-folder>/

每個 Skill 資料夾內必須包含一個 SKILL.md 說明檔。

# 1. 建立技能目錄
mkdir -p .agents/skills

# 2. 複製/下載 Skill (以 marketingskills 為例)
git clone https://github.com/coreyhaines31/marketingskills.git

# 3. 搬移所需 Skill 至專案工作區
cp -R marketingskills/skills/marketing-plan .agents/skills/
cp -R marketingskills/skills/copywriting .agents/skills/
